# TASKS.md

## UX priority

1. Main result should compare all structures.
2. Recommendation card should be the first result.
3. Single-structure selector should remain secondary to the comparison flow.
4. Conditional fields should reduce cognitive load.
5. English text should be removed from UI.
6. Error messages should be field-level and actionable.

## Regression watchlist

- Recommendation reasons must stay in Russian.
- Assumptions and warnings visible in the UI must stay translated or mapped to Russian copy.
- Real estate fields must not appear for non-real-estate income types.
- Key rate field must appear only for deposit interest.
- Formula and legal detail must stay behind progressive disclosure.
- Money input must continue to accept human-readable formats such as `5 000 000 ₽`, `5,000,000`, and `5000000,50`.
